# تكبير الصور وتحويلها إلى PDF

موقع ثابت (بدون سيرفر) يعمل بالكامل داخل المتصفح:

1. **تكبير الصورة** ×2 / ×3 / ×4 بخوارزمية Lanczos-3 مع تحديد حواف خفيف (بدون إعادة رسم أو تغيير المحتوى).
2. **OCR** عربي/إنجليزي (Tesseract.js) لاستخراج مكان كل كلمة.
3. **PDF** بنفس أبعاد الصورة: الصورة المكبّرة كخلفية + طبقة نص غير مرئية في نفس أماكن الكلمات، فيصير النص قابلًا للتحديد والنسخ والبحث.

كل المكتبات والخطوط ولغات OCR داخل `vendor/` فلا يعتمد على أي CDN.

## التشغيل محليًا
```
python3 -m http.server 8000
# ثم افتح http://localhost:8000/pdf-upscaler/
```
يعمل على GitHub Pages أو أي استضافة ملفات ثابتة (لازم HTTPS أو localhost).
